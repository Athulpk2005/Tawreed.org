# Logo placement register

The attached L2 Tawreed Flow v2 pack was reviewed as a coherent identity system. All seven native variants are included in `assets/brand/`, with selected digital icon sizes. Original source pixels, proportions and the indigo/periwinkle/teal current in the w are retained. No CSS recolouring, substitute lettering or gradient reconstruction is used.

| Variant | Site use | Reason |
|---|---|---|
| Full-colour compact wordmark | Shared navigation and modal wordmark | Stronger name recognition at compact digital sizes |
| Full-colour primary with descriptor | About and corporate-services identity panels; main portal card | The full identity has room for its centred descriptor |
| Reverse primary on indigo | Shared footer | Original white lettering and two-tone w on the supplied dark ground |
| Reverse compact wordmark | Dark CTA panels on detail pages | The intended reverse artwork matches a dark branded application |
| Square T identifier | Inner-page eyebrow identifiers, homepage identifier, portal utility identity, favicon and touch icon | Small digital utility treatment uses the supplied capital T tile |
| Indigo monochrome | Print header alternative | A supplied single-colour version for print output |
| White monochrome on indigo | Included production alternative | Reserved for genuinely single-colour dark applications; it is not forced into full-colour pages |

The supplied reverse variants include an opaque indigo background. They are displayed intact. The white monochrome and other native alternatives are packaged so a designer can choose the correct reproduction context without treating every file as a different brand. Full wordmarks and the T tile are never combined into an invented new logo lockup. The full-colour transparent exports previously trimmed only empty transparent margins for readable digital placement; they preserve the artwork itself.

Native files are raster PNGs, not editable SVG paths. The original pack does not provide a logo font or vector reconstruction. Code-native line icons and offline SVG backgrounds in this website are separate illustrations, not substitutes for the supplied logos.
